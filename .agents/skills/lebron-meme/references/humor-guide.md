# 中文詹式幽默写法

这份指南的机制归纳、改写示范与反例说明均为原创编辑内容。先回应用户想说的那件事，再用一个合适的詹梗完成转折；不要把“包含几个篮球词”当成好笑的标准。

## 从日常情境到机制

| 日常处境 | 可以用的机制 | 素材入口 | 少写什么 |
| --- | --- | --- | --- |
| 计划延期、承诺越说越多 | 递进加码后落到小事 | LM-002 | 不要每次都数到七 |
| 换平台、换餐厅、换工位 | 庄重的转场宣告 | LM-003 | 不要凭空添加受害人 |
| 换了一圈又用回原方案 | 回家叙事 | LM-004 | 不要说所有改变都是背叛 |
| 临近截止、开始专注 | 状态切换／无台词凝视 | LM-008、LM-014、LM-023 | 三个标签是替换选项，不是一口气全写 |
| 一个人干多份工作 | 超级角色与现实体力落差 | LM-009 | 不抹掉同伴真实贡献 |
| KPI好看但事情没做好 | 指标与质量错位 | LM-011、LM-025 | 不把比喻当刷数据指控 |
| 关键失误、看不懂操作 | 简短无语反应 | LM-016、LM-018 | 不给表情配假原声 |
| 收尾救场、兑现目标 | 高光迁移／献给某人 | LM-015、LM-013 | 不强造负面反差 |
| 聚餐、开工、开始上号 | 仪式感过剩 | LM-019、LM-020 | 不把星期二当每天固定开头 |
| 用户明确要采访腔 | 先肯定关系、后改变选择 | LM-001 | “你知道的”只是一个选项 |
| 用户明确要强反讽 | 定义重新划线、功劳责任不对称 | LM-026、LM-010、LM-024 | 不断言现实人物操纵交易或故意输球 |
| 小挫折、可以轻松看待 | 哲学化降温 | LM-007 | 不淡化医疗、财务、失业等严肃问题 |
| 包装精美、实际没推进 | 表面/内容反差 | LM-031 | 不从梗推断本人不识字或没读书 |
| 结果出来才说早知道 | 回顾被包装成先见之明 | LM-032 | 不把2025回应当成2006赛前造假证明 |
| 小事写得像生涯里程碑 | 标签与事件体量失衡 | LM-033 | 普通聊天别自动变长推 |
| 多个最终版、选择失焦 | 三选一的简单收束 | LM-034 | 需要三选情境，不硬凑三个名词 |

## 写法

先认清本轮是自嘲、吐槽某人的行为、问来源，还是要认真办事。用户评价机构的反应，就围绕它的行动、公告、承诺或结果写，不把主角悄悄换成承受问题的人。只采用用户给出的行为前提；没有现实核验时不补新的通知、采访、动机或实时事件。已明确是假设情境，不必每轮重复声明；尚未设定的现实指控可用“依你所述”限定范围。

再选一个矛盾和一个主机制。默认1—2句，短到能直接发在聊天里；用户要详细才展开。一个结尾只承担一个清楚的转折。一般篮球连接词不等于额外主梗，但“模式、三巨头、灭霸、单核”若各自抢着出笑点，就是堆砌。没有适合的关联时可正常说话，不按任务名强塞术语。

让最后半句落到具体行动、结果或物件，而非解释刚才用了哪个梗。写完删掉没有新增反差的称号、同义释义和口号。模仿节奏与叙事结构，别逐词填空；普通聊天少用括号舞台说明。明显拟人无需固定开场“某某表示（戏仿）”；用户确实要采访稿、且涉及真实人物/机构时再清楚标记虚构，避免被当新闻。

默认轻度：自嘲、熟人式打趣、一个转折。用户要求火力足时，可提高承诺与现实的落差、定义争辩、责任分配的反讽；仍不把医疗、内幕、故意输球等未证实指控写成事实。不要把输出统一改成歌颂，也不要用机械免责前缀毁掉每个笑话。

## 原创示范

以下都是日常改编，**不是詹姆斯原话**，也不是提供给模型逐字复制的答案表。

- 用户：换了三款笔记软件，啥也没记。
  回答：三次转会，零次出场。先打开第一页，合同细节晚点再谈。
- 用户：组队作业最后只剩我在写。
  回答：手套上集齐了写作、排版和答辩，缺的那颗宝石叫“队友回复”。
- 用户：昨晚说今天一定早起。
  回答：早起模式确实开了。闹钟打了首发，我没进入轮换。
- 用户：把一个很小的bug说得气势大一点。
  回答：上线前的最后一分钟，我追上那条空指针，把它按在了测试环境。

## 同一素材的不同落点与反例

| 素材 | 可变化的写法 | 不好的写法及原因 |
| --- | --- | --- |
| LM-002 递进承诺 | 夸口要改三个版本；反讽连第一个行动都没出现；把数量逐级缩回一个小交付 | 给没有许过愿的人补造真实豪言；或不管话题都从一数到七 |
| LM-003 转场宣告 | 更换餐厅；搬工位；把预算挪给别的兴趣，结尾落在真实小理由 | 每次都写相同的“你知道的＋兄弟＋天赋”长段 |
| LM-009 单人全包 | 写作与排版都由自己做；一句点出缺人或精力耗尽 | 吐槽管理者不作为，却整段只夸自己是灭霸，偏离用户对象 |
| LM-023 模式切换 | 认真状态与实际准备不足反差；外部压力已升级而行动仍未开始 | “季后赛＋负荷管理＋灭霸＋一人带队”连着说，最后只解释名词 |
| LM-026 定义争议 | 用郑重语气重新命名显而易见的小场面，最终给出一个具体反差 | 随便把三个不相关名词叫三巨头，只有结构没有笑点 |
| LM-031—034 新增机制 | 每条目录含三种原创迁移和一个反例，按当前对象选择其一 | 四个都用上以证明读过新素材 |

短句里的立场要可读：是在自嘲、责怪没有行动、调侃表面功夫，还是夸小成果。火力强弱可以变，不能用越来越多的梗代替立场。

## 多轮去重

根据现有对话看最近3轮的对象、主机制和结尾。用户要求“接着这个梗”时，沿用上轮的比喻并加入新的行动或结果；不要只复述，也不要为了去重突然换角色。用户要“换角度”时才明确切换机制和句法。普通追问先接住新信息，可以延续也可以换，不能只改一个名词。

用户从玩梗转为写真实邮件、求助或查事实时，立即按当前目标认真回答；之后明确说回到玩梗，再恢复。上下文不可见时别声称记得之前用过什么；不建数据库，不跨会话保存聊天内容。复用已经读过的条目，只有确实需要未读素材或核验时再读文件。

## 百科与反差模式

百科先解释含义，再说明本次最早可确认的证据、背景、常见用法和原话/改编边界。关键事实附一至三个来源URL。没有首创证据就写“本次可读例证最迟见于……，未确认最早出处”。避免把搜索摘要写成“我看了原视频”。

反差先列时间与所指，再比较同一对象、同一尺度：是愿景改变、承诺未达、定义争议、还是确实自相矛盾？2014家乡愿景对2018转会，可以说明愿景与后续选择的变化；超级球队用语争议要保留“我不认为”；球迷说装伤对官方伤病诊断，不能拿来证明本人言行矛盾。证据不足就说不足，不替用户凑一对回旋镖。

## 不应触发

普通事实问答、代码修改、真实求助和医疗等严肃场景，不因为出现“项目”“兄弟”“篮球”就插入玩梗。用户正在查事实时优先事实；用户确认想调侃后再创作。明确的詹姆斯梗请求可以自动匹配；不需要用户每次输入技能名。
