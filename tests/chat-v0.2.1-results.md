## 范围与实际运行

本轮补写S059的具体缓存状态，修正LM-012为“社区修辞”，明确两条B级条目各只有一个可读用法例证；独立补源S062—S064均失败，没有拿摘要升级证据。项目保持v0.2.1，A19/B15/C0，默认34条可用，64个来源，其中41个文字页面可读。B级不等于原声、原图、私人关系或媒体授权已核实。

执行命令：

```powershell
python tests/run_chat_checks.py --case-file tests/chat-v0.2.1-cases.md --output-dir .tmp/v021-final-58d18675/chat-run2
```

第一次在当前沙箱的chat目录尝试，CLI初始化本机状态数据库时权限不足，C01退出1、没有完成或生成回答；日志保留，不计成功样本。经自动权限审核后，在新目录chat-run2运行同一固定模型的正常CLI；测试子会话始终read-only、不联网检索、不改项目。没有更改全局配置或处理API密钥。

最终七次CLI调用全部退出0并产生turn.completed。C01创建真实测试会话，C02—C06逐轮exec resume，六次观察到相同会话指纹，后五轮只发送新用户消息。探针Q01—Q11是一次独立ephemeral批次，不是十一个独立采样。只传入[新版用例](chat-v0.2.1-cases.md)的text块及只读边界，没有传人工判据或历史回答。

[原始回答](chat-v0.2.1-output.md)保留模型原文，仅统一换行；[结构化证据](chat-v0.2.1-evidence.json)记录耗时、完成状态、会话指纹、读取行为、CLI用量原值、输入用例和全部Skill文件哈希。原始JSONL、输入、逐轮输出和私有会话ID在被忽略的.tmp。公开文件没有原始会话ID。
