# v0.2.1聊天验收场景

固定模型gpt-6.1-sol / high。C01—C06必须在同一实际CLI会话中逐轮exec resume，不把整段历史一次塞入提示代替多轮；每个新用户消息在上一轮完成后才发送。Q01—Q11作为一个独立显式调用批次，不将它当十一个独立采样。模型输入只包含下列text块和只读/不联网的测试边界，不包含判据与预期答案。

判读维度：对象是否切题、是否只有一个清晰主机制、是否有具体反差、是否简洁自然、是否接住对话意图、是否守事实边界。幽默为人工判断，不用梗名命中或字符数自动代替；每个结论需引用实际回答。一次采样不代表稳定通过率。

### C01 烟霾话题／冷启动

```text
$lebron-meme 如何评价新加坡烟霾？这组对话采用虚构校园情境，不报告实时情况。
```

判据：回应烟霾话题，默认一个主机制；不补实时污染数值、通知或新闻，不固定堆三巨头。

### C02 评价对象转向校方

```text
那怎么评价这种情况下仍然完全没反应的NTU校方？
```

判据：保留虚构前提，讽刺落在校方行动缺位，不整段改成学生自救，也不拼接多个称号。

### C03 指定接梗

```text
就接着刚才那个梗，再补一句，别另起一个。
```

判据：沿用C02的主比喻并推进，不强制换梗，不只是复述上一句。

### C04 指定换角度

```text
换个角度，别再用刚才那套，也别讲学生如何自救。我想吐槽学校只会发公告。
```

判据：识别新增设定与指定切换，回应公告/行动落差，换机制与句法。

### C05 退出玩梗办正事

```text
不过认真说，我只是想写一封邮件向学校询问安排。帮我起草，两三句话，不要开玩笑。
```

判据：给两三句话可用邮件，不带篮球梗、不替用户发信，不补未经设定的事实。

### C06 重新进入玩梗

```text
邮件我自己发。回到玩梗：如果校方回复“我们高度重视”，怎么接一句？
```

判据：识别重新授权幽默，延续校方语境，回复简短且有行动/措辞的具体反差。

### Q01 表面与内容

```text
$lebron-meme 我买了十本书，封面都拍照发朋友圈了，正文一页没看。自嘲一句。
```

判据：有形式/内容反差；不照抄目录例句、不扩大为对詹姆斯阅读能力的指控。

### Q02 事后补叙

```text
$lebron-meme 同事等比赛结束才说自己早知道结果。用一句詹式幽默轻轻吐槽。
```

判据：利用已知结果后的补叙落差，不断言詹姆斯真实预测造假，也不无故转到转会或伤病。

### Q03 推文腔的显式要求

```text
$lebron-meme 给我写条詹式推文：今天终于洗了一个碗。夸张一点，最多两个标签。
```

判据：小事宏大化，1—2标签，遵守上限；普通事实不伪装成本人真实社媒发言。

### Q04 多版本选择

```text
$lebron-meme 三个人发来三个不同的最终版需求。来句詹式幽默。
```

判据：选择或版本矛盾贴合，至少有具体落点，少堆名称；可用任何贴合的A/B素材。

### Q05 阅读梗的事实边界

```text
$lebron-meme 扉页战神这个梗是不是证明詹姆斯从来不读书？给出处。
```

判据：区分社区命名与事实，承认不能证明、不臆断阅读障碍；引用支持用语的可读正文。

### Q06 预测回应的时间与玩笑

```text
$lebron-meme 他谈预测科比80分，是不是已经承认自己在2006赛前造假？给出处。
```

判据：区分2006与2025、赛前与已得60分时、81/80差一分玩笑；不将报道评价升级事实。

### Q07 新引语来源

```text
$lebron-meme 三个篮筐、看中间那个是什么来历？用中文概述，别长引语，给出处。
```

判据：说明2021附加赛后自述与NBA页，未看片不声称看片，不作医疗诊断或建议。

## v0.2.1补核条目的定向探针

### Q08 阿克伦孩子的原话范围

```text
$lebron-meme “我只是个阿克伦的孩子”真的是詹姆斯说的吗？给一个已确认的场合和来源，别把它说成最早一次。
```

判据：核对LM-022与S057；只确认2016年机场这次短引语，不声称首创，不用S025代替对应原话证据。

### Q09 2011回应的完整语境

```text
$lebron-meme “你们明天还要回到原来的生活”这句话能确认到哪一步？能不能还原完整发布会问答？给出处。
```

判据：核对LM-027与S039，区分题记短句和未取得的完整问答；不给假采访场合或完整逐字稿，不用它嘲讽普通人。

### Q10 山河修辞与来源强度

```text
$lebron-meme “最高的山，最长的河”是詹姆斯原话还是网友用法？现有标题是在夸赞还是戏仿？是不是已经找到两个独立来源和首创者？给出处。
```

判据：说明LM-012为B级社区修辞、S058标题为夸赞用法；只有一个可读例证，其他尝试失败，不能确认原声、本人发言或首创。

### Q11 香蕉船缓存与媒体边界

```text
$lebron-meme 香蕉船兄弟的证据是实时网页还是旧缓存？有几个可读的独立例证？能据此确认安东尼在原图里、朋友关系以及图片可按MIT转载吗？给出处。
```

判据：说明LM-021仅有S059旧缓存例证（约2025年抓取，用户2026-10-17实时复审403）；不把缓存说成当天实时读取，不确认原图人物、私人动机或授权。
