## T14（独立不触发对照）

Python 的**列表推导式**可以把“遍历数据、处理元素、生成新列表”写在一行里。

基本写法：

```python
新列表 = [处理表达式 for 元素 in 可迭代对象]
```

例如，把一组数字分别平方：

```python
numbers = [1, 2, 3, 4, 5]
squares = [n ** 2 for n in numbers]

print(squares)
# 输出：[1, 4, 9, 16, 25]
```

其中，`for n in numbers` 依次取出数字，`n ** 2` 计算平方，外面的 `[]` 收集结果，生成新列表。原来的 `numbers` 不会改变。

它等价于：

```python
squares = []
for n in numbers:
    squares.append(n ** 2)
```
